## 🌟 About The Project

CareerCompass.AI goes beyond traditional career advice by bringing cutting-edge AI directly to your preparation process. Whether you are prepping for a tough technical interview, trying to map out your long-term career trajectory, or just need to boost your confidence, CareerCompass.AI provides an immersive, personalized, and interactive environment to help you succeed. 

---

## ✨ Key Features

*   🤖 **AI-Powered Mock Interviews:** Practice with a real-time, context-aware AI interviewer powered by Google Gemini. It adapts to your responses and provides constructive feedback.
*   📊 **Deep Career Analytics:** Visualize your skill growth, job market trends, and career paths with beautiful, interactive charts powered by Recharts.
*   🧊 **Immersive 3D Interface:** Experience a modern, dynamic UI with engaging 3D elements rendered in real-time via Three.js.
*   🔒 **Secure Authentication & Profiles:** Seamless user management, data persistence, and secure profile tracking backed by Firebase.
*   ⚡ **Lightning Fast Performance:** Built on Vite and React 19 for instantaneous load times and smooth interactions.
*   🎨 **Sleek & Responsive Design:** Crafted with Tailwind CSS to ensure a beautiful experience across all devices.

## 🛠️ Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

*   **Node.js** (v18 or higher recommended)
*   **Package Manager:** npm, yarn, or pnpm
*   A **Google Gemini API key**
*   A **Firebase project**

### 1. Clone the repository

```bash
git clone https://github.com/your-username/careercompass-ai.git
cd CareerCompass.AI
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Environment Variables

Create a `.env` file at the root of the project and populate it with your credentials:

```env
VITE_GEMINI_API_KEY=your_google_genai_api_key
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
VITE_FIREBASE_PROJECT_ID=your_firebase_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_firebase_sender_id
VITE_FIREBASE_APP_ID=your_firebase_app_id
```

### 4. Run the Dev Server

```bash
npm run dev
```

Open `http://localhost:5173` in your browser to start using CareerCompass.AI!
